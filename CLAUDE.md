# LeaseRight project guidance (branch `rebuild/ri-foundation`)

## Status

This branch is the new foundation for LeaseRight, approved by Justin on 2026-10-07. `main` and
leaserightbeta.netlify.app still run the static prototype (`LeaseRight.html` plus
`components/*.jsx`). They stay that way until the operating console is rebuilt here and wired
to real projects. Then there is one cutover and the old tree is archived.

Read `PROJECT.md` and `PRODUCT_DIRECTION.md` before working. `spec/OVERSEER_MODEL_AND_AGENT_SYNTHESIS.md`
remains the controlling business source.

## One codebase

- Do not start a second copy of the app anywhere (another folder, another repo, a `v2/`
  directory). New work lands on this branch.
- Do not port files from `main`'s `components/` wholesale. Rebuild a surface here against
  `src/store/store.jsx` so it runs on the user's real project, not on sample data.
- Do not add features until the listing feed has run once on real data and been checked.

## What is here and what is not

Built, front end only: project overview with a next-step prompt; the Model (guided intake for
36 Rhode Island towns, scheduled rent data, similarity-ranked comparables, the lease-up reserve
model, baseline approval); the lender package from the saved baseline, printable to PDF; the
operating console in the old prototype's look (Today decisions, Pipeline board, Inbox, Rents
and concessions, Applications, Listings syndication, Units, Market, Reports) running on the
project's own prospects and units, with weekly numbers derived from the pipeline; a simulated backend (`src/core/sim.js`) that stands in for lead intake, the leasing
agent, tours, screening, e-signature and listing sync, driven by a day-by-day clock, with practice
lease-ups for any project with a baseline; a fictional sample project whose history the simulation produces.
Planning-agenda data appears as market activity only, never as a way to start a project.

The real services are designed in `docs/BACKEND.md`. A stand-in and its real service must write the
same fields; change both together.

Not built: accounts and sync (deliberately deferred until the workflow is settled), inbound
lead capture, posting to listing sites, credit checks and online applications, lease documents, payments, roles, broker versus
in-house economics, a second state.

## Conventions

- This branch has a build step: Vite, React 18, Vitest. The build-free rule applies to `main` only.
- `src/core/` is pure logic with unit tests. No React and no network calls in it.
- Everything specific to Rhode Island stays in `src/ri/` and `tools/`.
- All persistence goes through `src/store/store.jsx`.
- `pipeline/*.json` are the source ledgers. `public/data/*.json` are generated by
  `tools/build_data.py`. Fix the ledger, never the published copy.
- A change to anything in `src/core/` needs a test in `tests/`.

```bash
python3 tools/test_harvest.py
python3 tools/build_data.py --check
npm run build                        # writes dist/
```
