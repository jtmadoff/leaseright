LeaseUp — Property Management, Rebuilt.
========================================

To preview the prototype:

1. Go to https://stackblitz.com/fork/react
2. Replace the contents of App.jsx with LeaseUp_Prototype.jsx
3. In the terminal at the bottom, run: npm install recharts
4. The app will render automatically

That's it. Click through the sidebar to see all 12 modules.

Files:
- LeaseUp_Prototype.jsx  — Full interactive React prototype (12 modules, 2200+ lines)
- LeaseUp_Technical_Spec.docx — Technical architecture document
